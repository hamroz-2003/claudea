# FlowCraft Engine

Backend for the FlowCraft Studio app (Android / browser).

1. Click **⋮ → Duplicate this Space** (free "CPU basic" hardware is enough).
2. In the copy: **Settings → Variables and secrets → New secret**: `FLOWCRAFT_TOKEN` = a long random password.
3. Open the FlowCraft Studio app, enter this Space's address (`https://<you>-<space>.hf.space`) and the token.

Free Space storage is temporary: download finished videos; projects may disappear when the Space restarts.
